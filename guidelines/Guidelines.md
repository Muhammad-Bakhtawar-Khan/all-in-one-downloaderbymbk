# MBK interface guidelines

- Keep the existing MBK dark, utility-first interface intact: charcoal ground, warm gold accent, precise thin rules, DM Mono for labels and Manrope for body copy.
- Treat the downloader as a strict utility. Format availability and error states must be clear, honest, and derived from the real provider response.
- Use the supplied MBK portrait, social URLs, and Pinterest visuals only in MBK-owned home/profile contexts. Keep image layouts structured, restrained, and responsive.
- Prefer compact Swiss-style alignment and direct labels over decorative redesigns. Preserve the existing spacing, hierarchy, and responsive behavior when extending a view.
